# MoodTradeSimulator

MoodTradeSimulator is an Android application designed to help users learn trading concepts while understanding the impact of emotions on investment decisions.

## Features

* Simulated stock trading environment
* Portfolio management
* Buy and sell functionality
* Mood tracking and sentiment features
* Market browsing and stock search
* Room database persistence
* Portfolio reset functionality

## Technologies Used

* Java
* Android Studio
* Room Database
* RecyclerView
* XML Layouts

## Purpose

This project was developed as a final-year computing project to explore how emotional factors can influence trading behaviour and decision-making.
